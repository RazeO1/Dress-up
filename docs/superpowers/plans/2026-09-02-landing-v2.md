# TAG Landing Page v2 Implementation Plan

> **For agentic workers:** Use executing-plans or subagent-driven-development.

**Goal:** Awwwards-worthy editorial landing page with custom cursor, film grain, kinetic typography, pinned scroll scenes, and a single coherent magazine-cover design language.

**Architecture:** 8 sections + persistent overlay layer (cursor, grain, progress, nav). Each overlay component is fixed/absolute. Sections flow vertically. All animations via framer-motion `useScroll`/`useTransform`. The 3D tag and shadergradient stay only in the hero.

**Tech Stack:** Next.js 14, TypeScript, Tailwind CSS v3, framer-motion 13, @react-three/fiber, @shadergradient/react, three.js

**Spec:** `docs/superpowers/specs/2026-09-02-landing-v2-design.md`

## Global Constraints

- **No new dependencies.** framer-motion only for animations.
- **No external images.** SVG illustrations inline for all visual interest.
- **3D only in hero.**
- **Custom cursor on all interactive elements** — `cursor: none` on `html`, replaced by the cursor overlay.
- **Palette**: `#FFF8F0` cream / `#1A1A1A` charcoal / `#A8FF3E` acid green (sparingly) / `#8A8A7A` muted.
- **Type**: Playfair Display 700 (headlines), IBM Plex Mono 400 (body), Space Mono 400 (labels).
